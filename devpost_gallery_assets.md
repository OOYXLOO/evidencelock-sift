# Devpost Gallery Assets

Use these assets in this order when the Devpost project draft is available:

1. `docs/proof-card.png` or `docs/proof-card.svg`
   - First image.
   - Shows the core value proposition: a confirmed finding tied to evidence, tool calls, verifier self-correction, and integrity hashes.
2. `docs/architecture.png` or `docs/architecture.svg`
   - Second image.
   - Shows trust boundaries between evidence, typed DFIR tools, the agent loop, verifier, and reports.
3. `reports/investigation_report.md`
   - Use as a screenshot or linked artifact.
   - Shows the final finding format with evidence refs and tool refs.
4. `reports/execution_log.jsonl`
   - Use as a screenshot or linked artifact.
   - Shows command IDs for hash, parse, search, failed verification, and successful verification.

Prefer PNG uploads for Devpost gallery compatibility. Keep the public raw SVG/Markdown links in the project description even if the gallery upload succeeds.
